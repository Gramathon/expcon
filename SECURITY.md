# Security Policy

## Supported versions

EXPCON is under active development and does not currently make a formal security
support commitment for released versions. When reporting an issue, include the
EXPCON version or commit, Python version, and operating system if known.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting form](https://github.com/Gramathon/expcon/security/advisories/new)
when it is available. Do not report suspected vulnerabilities in a public issue
or pull request, and do not include live credentials or unrelated private data.

If private reporting is unavailable, contact the maintainer using the private
contact method listed on the [@Gramathon GitHub profile](https://github.com/Gramathon)
and ask for a secure reporting channel. Include a concise description, impact,
affected version or commit, and steps to reproduce that do not expose real user
data.

There is no guaranteed response or remediation timeline. Please allow the
maintainer an opportunity to investigate before publicly disclosing a suspected
vulnerability.
